\section{Preregistered evaluation}
\label{sec:planned}

\paragraph{E3d: qualify the measurement instrument.}
Fresh development banks 360--361 compare the unchanged current contract, one
query-anchored label-only contract, and a diagnostic structured verifier. Matched
single- and dual-path ledgers cross AND2/AND3, lexical nuisance, base/counterfactual
worlds, query role, and targeted evidence masks: empty, exact support, full, every
missing link, missing-link plus distractors, and competing-query-only. Only the
unchanged label-only candidate may proceed to a single verification run on banks
370--373. It must pass every frozen aggregate and per-link readiness check. A
structured-only success defines a different hybrid-system hypothesis.

\paragraph{E4: H1 and H3a.}
After E3d only, fit all policies on complete past games and freeze masks before
opening paraphrased future queries. Required baselines include exact Shapley,
budget-conditioned marginals, leave-one-out, additive regression, a faithfully
specified MemLens-style method, an online-observable item scorer inspired by OSL-MR,
random, recency, query overlap, and lexical centrality. Quadratic and cubic selectors
share the same calls and budgets. Full and empty memory are reference conditions,
whose outcomes remain \TODO{unobserved}.

The current practical margin of .03 is illustrative, not a frozen confirmation
claim. A separate variance-only pilot must determine an achievable bank count.
Fixing twelve banks from variance in a different failed setting would be
underpowered if the bank-level standard deviation were materially larger.

\paragraph{E4b: H3b compositional shift.}
A separately versioned generator must change target identifiers, topology, motif
mixture, path overlap, distractors, and query composition between past and future.
The shift strata and interaction-by-shift analysis are frozen. H3a cannot be
generalized to temporal or compositional stability.

\paragraph{E5: H2.}
On a reserved cohort, enumerate matched lesion pairs using past evidence only.
Balance deletion count, bytes/tokens, multiple item scores, recency, frequency,
centrality, record position, and \(J_-\), while separating \(G\). Report standardized
balance, all pair identities, placebo effects, and bank-level damage. The primary
effect and interval are \TODO{unobserved}.

\paragraph{External validity and efficiency.}
Only after H1 and H2 pass, evaluate source-level deletion on audited subsets of
LoCoMo and LongMemEval with identical retrieval and a second reader family. Report
accuracy, evidence recall, abstention, contradiction/update behavior, model calls,
input/output tokens, latency, storage, and peak accelerator memory. Vary polynomial
order, coalition sample budget, regularization, memory order, capacity, irrelevant
records, contradictions, corruption, and temporal gaps. Plot quality against total
estimation and inference cost. A synthetic-only advantage is a falsification of a
broad systems claim.
