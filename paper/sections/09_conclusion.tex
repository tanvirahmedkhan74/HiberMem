\section{Conclusion}

External-memory retention is a subset-selection problem, and compressing an
arbitrary memory game into item scores can discard coalition identity even though
ordinary Shapley values correctly allocate interaction worth. This observation makes
coalition-aware retention plausible, not proven. We have formalized the relevant
estimands, implemented a leakage-safe prospective protocol, and corrected the
planned lesion to respect interaction sign. The completed real-model evidence
instead reveals a prior measurement problem: formatting and evidence-grounded
abstention can move in opposite directions. Because no output contract passed the
frozen screen, the prospective and lesion hypotheses remain open. The next result
that matters is therefore not a larger claim; it is whether a fresh, label-only E3d
reader passes without unsupported completion. If it does, H1--H3 can be tested. If
it does not, the current HiberMem method claim should stop.
