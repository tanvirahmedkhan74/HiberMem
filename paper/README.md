# ICLR 2027 evidence-bounded draft

This directory contains a new manuscript built from the official ICLR 2027 style
files. It intentionally does not reuse the claim structure or bibliography in
gemini/. Unknown prospective results are marked TODO.

Build from this directory with:

    tectonic main.tex

The submission mode is anonymous. Do not uncomment iclrfinalcopy until camera-ready.
Before submission, manually verify every citation and AI-use disclosure, replace
only validated TODOs, and confirm that main text remains within the current ICLR
limit.
